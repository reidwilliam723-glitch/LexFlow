## Description of Service

LexFlow is a Windows typing assistant. It can:

- Suggest word completions and spelling fixes while you type
- Suggest grammar fixes
- Expand text shortcuts
- Optionally rewrite selected text using an AI provider you configure
- Process most assistance locally on your PC

## Optional AI providers

Cloud AI is **off** unless you choose a provider in Settings and supply that provider's credentials (or run a local model). Everyday dictionary suggestions do not require an AI account.

Available providers in the Software:

| Provider | How it runs | Typical use |
| --- | --- | --- |
| **OpenAI** | Cloud API (your API key) | Completions and rewrite |
| **Google Gemini** | Cloud API (your API key) | Completions and rewrite |
| **DeepSeek** | Cloud API (your API key) | Completions and rewrite |
| **Ollama** | Locally on your machine | Completions and rewrite without a cloud key |
| **None** | No AI provider | Dictionary, spelling, and local grammar only |
